# 智衡 Copilot 预览版部署手册

> 本手册用于当前预览版本的部署；由于预览版本仍在测试阶段，整体部署流程以“能跑通”为优先，所有步骤均通过仓库根目录下的 `build-and-start.ps1` 一键完成。覆盖后端 Docker 部署、前端构建与发布、默认账号与安全注意事项。

## 1. 交付范围

当前版本已包含以下能力，用户可直接通过浏览器访问体验：

- 登录与默认账号（系统管理员 / 普通用户）
- 系统管理：账号创建、删除、管理员权限设置
- 系统管理：项目成员分配（项目负责人 `manager` / 项目成员 `implementer`）
- 项目创建（项目编号自动生成）
- 项目工作区文件上传、交付物追踪
- 项目快照与标签时间线
- AI 任务：项目总结、合同 / 发票 / 回款单据解析
- 统计看板与风险监测

## 2. 环境准备

- 操作系统：Windows Server，或已安装 PowerShell Core 的 Linux
- Docker >= 24.0（Windows 建议 Docker Desktop）
- Docker Compose >= 2.20
- Node.js >= 20
- npm >= 10
- 公网 IP（用于测试访问）

## 3. 配置环境变量

在仓库根目录创建 `.env` 文件，Docker Compose 会自动读取。最小配置如下：

```env
CORS_ORIGINS=http://<服务器公网IP>:4173,http://localhost:4173
SEED_ADMIN_PASSWORD=ChangeMe2026!
SEED_DEMO_PASSWORD=Demo2026!
LLM_PROVIDER=mock
```

说明：

- `CORS_ORIGINS` 必须包含前端预览地址 `http://<服务器公网IP>:4173`，否则浏览器请求会被后端拒绝。
- `SEED_ADMIN_PASSWORD` 和 `SEED_DEMO_PASSWORD` 用于首次启动时创建默认账号。
- `LLM_PROVIDER=mock` 表示 AI 使用模拟数据；如需真实解析，改为 `kimi` 并填写 `KIMI_API_KEY`。

## 4. 一键启动

```powershell
cd zhiheng-copilot
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\build-and-start.ps1
```

`build-and-start.ps1` 会依次执行：

1. `cd client && npm run build`：构建前端生产包
2. `docker compose up --build -d`：启动后端 API 与 PostgreSQL
3. `npm run preview -- --host`：启动前端预览服务器（已绑定 `0.0.0.0`，允许公网访问）

脚本会一直占用前台，按 `Ctrl+C` 退出时自动执行 `docker compose down`。

## 5. 访问服务

启动成功后，通过浏览器访问：

| 服务 | 地址 |
|---|---|
| 前端页面 | `http://<服务器公网IP>:4173` |
| 后端 API | `http://<服务器公网IP>:8086` |
| 数据库 | `localhost:8088`（仅服务器本地） |

注意：安全组或防火墙需要放行 `4173`（前端预览）和 `8086`（后端 API）。

## 6. 验证部署

登录接口测试：

```bash
curl -X POST http://<服务器公网IP>:8086/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"login":"admin","password":"ChangeMe2026!"}'
```

返回 `token` 即表示后端运行正常。

浏览器访问前端页面后，建议验证：

- 使用 `admin` 账号登录
- 进入“系统管理”页面创建新账号
- 创建新项目
- 分配项目负责人 / 项目成员
- 上传文件并触发 AI 任务

## 7. 默认账号与使用说明

首次启动后系统会自动创建：

| 登录名 | 密码 | 角色 |
|---|---|---|
| `admin` | `.env` 中 `SEED_ADMIN_PASSWORD` 的值 | 系统管理员 |
| `demo` | `.env` 中 `SEED_DEMO_PASSWORD` 的值 | 普通用户 |

管理员登录后，可在顶部导航进入“管理”页面，创建自有账号、项目及成员。

## 8. 安全注意事项

- [ ] 首次部署后务必修改 `SEED_ADMIN_PASSWORD` 和 `SEED_DEMO_PASSWORD`
- [ ] `CORS_ORIGINS` 只写实际访问地址，不要填 `*`
- [ ] 数据库端口 `8088` 不要对外开放
- [ ] `AUTH_DISABLED` 保持 `false`
- [ ] 预览阶段使用 HTTP 即可，正式上线前再补充 HTTPS

## 9. 停止与重启

- 停止：在运行 `build-and-start.ps1` 的窗口按 `Ctrl+C`，脚本会自动停止前端预览并执行 `docker compose down`
- 重启：再次运行 `.\build-and-start.ps1`

如果只需要停止后端，可另开一个终端执行：

```powershell
docker compose down
```

## 10. 常见问题

### 10.1 前端登录提示“请求失败”

- 浏览器 F12 查看具体报错，确认是 CORS 问题还是后端未启动
- 检查 `.env` 中 `CORS_ORIGINS` 是否包含 `http://<服务器公网IP>:4173`
- 检查后端容器状态：`docker compose ps`

### 10.2 数据库连接失败

- 检查 PostgreSQL 容器是否健康：`docker logs zhiheng-copilot-db-1 --tail 50`
- 检查 `DATABASE_URL` 中的主机名是否为 `db`

### 10.3 文件上传失败

- 检查 `api_data` Docker Volume 是否挂载成功
- 检查容器内 `/data` 目录是否有写入权限

### 10.4 修改密码

当前版本暂未提供修改密码页面。如需修改，进入 API 容器执行：

```bash
docker exec -it zhiheng-copilot-api-1 python -c "
from app.core.security import hash_password
print(hash_password('新密码'))
"
```

然后将输出的哈希值更新到数据库 `user_account.password_hash` 字段。
