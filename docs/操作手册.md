# 智衡 Copilot 操作手册

本文档面向开发/测试人员，介绍系统默认账号、登录方式、项目与任务创建、成员角色分配及密码修改等常见操作。

## 1. 默认账号

首次启动并执行数据库迁移后，系统会自动创建两个默认账号：

| 登录名 | 默认密码 | 角色 | 说明 |
|---|---|---|---|
| `admin` | `admin-dev-only` | 系统管理员 | 拥有全部权限 |
| `demo` | `demo-dev-only` | 普通用户 | 仅拥有被分配项目的权限 |

默认密码可在 [`docker-compose.yml`](../docker-compose.yml) 中通过环境变量修改：

- `SEED_ADMIN_PASSWORD`
- `SEED_DEMO_PASSWORD`

## 2. 登录并获取 Token

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "login": "admin",
  "password": "admin-dev-only"
}
```

成功响应示例：

```json
{
  "token": "<bearer-token>",
  "expires_at": "2026-08-18T01:00:00Z",
  "user": {
    "id": 1,
    "login": "admin",
    "name": "系统管理员",
    "is_admin": true
  }
}
```

后续所有受保护接口需在请求头中携带：

```
Authorization: Bearer <bearer-token>
```

## 3. 创建新账号

### 3.1 通过前端页面

管理员登录后，顶部导航会显示**管理**入口。进入系统管理页后，在“账号管理”卡片中填写登录名、姓名、密码，并勾选是否设为管理员，点击**新建账号**即可。账号列表中会展示已有账号，点击**删除**可移除指定账号（删除后该账号的会话会立即失效）。

### 3.2 通过 API

若不使用前端，可直接调用 admin 接口（仅 `is_admin = true` 用户可调用）：

```http
POST /api/v1/admin/users
Authorization: Bearer <admin-token>
Content-Type: application/json

{
  "login": "newuser",
  "name": "新用户",
  "password": "new-password",
  "is_admin": false
}
```

配套接口：

- `GET /api/v1/admin/users`：账号列表。
- `DELETE /api/v1/admin/users/{user_id}`：删除账号。

约束说明：

- `login` 全局唯一，重复会返回错误。
- 密码长度不得少于 8 位。
- 删除操作不可撤销，请避免误删内置账号或当前正在使用的管理员账号。

## 4. 创建新项目

### 4.1 通过前端页面

在任意项目列表页点击**新建项目**，填写项目信息后提交即可。弹窗中的“项目编号”字段已移除，系统会自动生成唯一编号，无需手动填写。

### 4.2 通过 API

```http
POST /api/v1/projects
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "XX 客户项目",
  "customer_name": "XX 客户",
  "project_type": "软件销售",
  "parties": [{ "role": "甲方", "name": "XX 客户" }],
  "signed_date": "2026-01-01",
  "started_date": "2026-01-05",
  "planned_delivery_date": "2026-06-30",
  "status": "active",
  "progress": 10
}
```

说明：

- 系统管理员（`is_admin = true`）可直接创建项目。
- 普通用户必须是某个现有项目的 `manager`，才能创建新项目。
- 项目创建成功后，创建者会自动成为该项目的 `manager`。
- `code` 字段可选；未填写时后端自动生成形如 `PRJ-XXXXXXXX` 的项目编号，唯一冲突时最多重试 5 次。

## 5. 创建 AI 任务

### 5.1 生成项目总结

```http
POST /api/v1/projects/{project_id}/summary
Authorization: Bearer <token>
```

返回任务 ID，可通过 `GET /api/v1/tasks/{task_id}` 轮询执行状态。

### 5.2 根据回答重新生成总结

```http
POST /api/v1/projects/{project_id}/summary/answers
Authorization: Bearer <token>
Content-Type: application/json

{
  "answers": [
    { "question": "当前进度如何？", "answer": "已完成 80%" }
  ]
}
```

### 5.3 解析合同 / 发票 / 回款单据

```http
POST /api/v1/versions/{version}/extract
Authorization: Bearer <token>
```

`version` 为文件版本哈希，对应 `FileVersion` 的 `version` 字段，且该版本的 `document_type` 需为 `contract`、`invoice` 或 `payment`。

## 6. 分配项目负责人

### 6.1 通过前端页面

管理员进入**系统管理**页，在“项目成员分配”卡片中选择目标项目，再选择要添加的用户，角色选择**项目负责人**，点击**添加成员**即可。已添加的成员会显示在项目成员列表中，点击**移除**可取消分配。

### 6.2 通过 API

```http
POST /api/v1/admin/projects/1/members
Authorization: Bearer <admin-token>
Content-Type: application/json

{
  "user_id": 3,
  "role": "manager"
}
```

说明：

- 仅系统管理员可调用该接口。
- 调用前目标项目与用户必须已存在。
- 同一用户在同一项目中只能有一种角色；重复分配会返回冲突错误。
- 分配成功后该用户即具备项目 `manager` 权限。

查询与移除：

```http
GET /api/v1/admin/projects/1/members
Authorization: Bearer <admin-token>

DELETE /api/v1/admin/projects/1/members/3
Authorization: Bearer <admin-token>
```

## 7. 分配项目成员

### 7.1 通过前端页面

与分配负责人相同：进入**系统管理**页“项目成员分配”卡片，选择项目与用户后，将角色切换为**项目成员**，点击**添加成员**。移除操作同样在该列表中完成。

### 7.2 通过 API

```http
POST /api/v1/admin/projects/1/members
Authorization: Bearer <admin-token>
Content-Type: application/json

{
  "user_id": 4,
  "role": "implementer"
}
```

移除：

```http
DELETE /api/v1/admin/projects/1/members/4
Authorization: Bearer <admin-token>
```

`role` 可选值：

- `manager`：项目负责人，可管理项目、上传文件、创建交付物等。
- `implementer`：项目成员，可查看项目、上传文件，但不能管理项目元数据。

## 8. 修改密码

当前系统**未提供修改密码接口**。如需修改用户密码，请直接操作数据库：

1. 进入后端容器或连接数据库。
2. 使用后端 `app.core.security.hash_password("新密码")` 生成 `password_hash`。
3. 更新 `user_account` 表的 `password_hash` 字段。

示例（在容器内执行 Python）：

```python
from app.core.security import hash_password
print(hash_password("new-password"))
```

## 9. 常用 API 速查

| 方法 | 路径 | 说明 | 最小权限 |
|---|---|---|---|
| POST | `/api/v1/auth/login` | 登录 | 无 |
| GET | `/api/v1/auth/me` | 获取当前用户信息 | 已登录 |
| GET | `/api/v1/admin/users` | 账号列表 | admin |
| POST | `/api/v1/admin/users` | 创建账号 | admin |
| DELETE | `/api/v1/admin/users/{user_id}` | 删除账号 | admin |
| GET | `/api/v1/admin/projects/{project_id}/members` | 项目成员列表 | admin |
| POST | `/api/v1/admin/projects/{project_id}/members` | 分配/变更项目成员角色 | admin |
| DELETE | `/api/v1/admin/projects/{project_id}/members/{user_id}` | 移除项目成员 | admin |
| GET | `/api/v1/projects` | 项目列表 | 已登录 |
| POST | `/api/v1/projects` | 创建项目 | manager |
| GET | `/api/v1/projects/{id}` | 项目详情 | implementer |
| PATCH | `/api/v1/projects/{id}` | 更新项目 | manager |
| POST | `/api/v1/projects/{id}/files` | 上传工作区文件 | implementer |
| POST | `/api/v1/projects/{id}/tracked-files` | 将文件提升为交付物 | manager |
| POST | `/api/v1/projects/{id}/summary` | 创建项目总结任务 | implementer |
| POST | `/api/v1/versions/{version}/extract` | 创建单据解析任务 | implementer |
| GET | `/api/v1/statistics/overview` | 统计看板 | 已登录 |
